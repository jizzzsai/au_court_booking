# AU Campus Court Local Build Plan

This project follows the backend proposal and is being built in testable stages.

1. Application foundation and first local interface
2. Prisma sports data model and database migrations
3. Court, facility, category, availability, and booking APIs
4. Student login and JWT session flow
5. Student, Staff, and Administrator role authorization
6. Booking conflict prevention, cancellation, and history
7. Google Maps facility links and peer API key integration
8. Automated tests, security review, and local production build
9. Linux VPS, Nginx, HTTPS, and Azure Key Vault deployment

The existing `crud-api` coursework project remains unchanged.
